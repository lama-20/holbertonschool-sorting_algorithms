# Sorting Algorithms Project

This project implements and compares different sorting algorithms in C as part of a low-level programming assignment.

## Algorithms Implemented

- Bubble Sort
- Insertion Sort (doubly linked list)
- Selection Sort
- Quick Sort (Lomuto partition scheme)

## Features

- Each algorithm sorts data in ascending order.
- The array or list is printed after every swap operation to visualize the sorting process.
- Implementations focus on in-place sorting for efficiency.
- Quick Sort uses the last element as pivot (Lomuto partition).

## Files

- 0-bubble_sort.c → Bubble sort implementation
- 1-insertion_sort_list.c → Insertion sort for doubly linked list
- 2-selection_sort.c → Selection sort implementation
- 3-quick_sort.c → Quick sort implementation
- print_array.c / print_list.c → Helper functions for output
- sort.h → Header file with prototypes and structures
- *-O files → Time complexity analysis (Big O notation)

## Complexity

Each algorithm includes best, average, and worst case time complexities in separate files.

---

This project helps understand sorting algorithms behavior, efficiency, and memory manipulation in C.
